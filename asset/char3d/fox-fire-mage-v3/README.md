# 여우 불술사 v3

- 사람 얼굴·여우 귀·꼬리 하나인 기존 Tripo 모델을 유지했습니다.
- 걷기: 팔을 반대쪽 발의 이동에 맞췄습니다. 같은 쪽 손발의 상관계수는 약 -0.89, 반대쪽은 0.999 이상입니다.
- 측면: 목과 골반을 잇는 선의 기울기를 뒤쪽 7.43도에서 앞쪽 4.07도로 바꿨습니다.
- 손의 기존 덩어리 불을 제거하고, 둥근 마법구·움직이는 불꽃 5개·상승하는 불씨 4개를 추가했습니다. 외부 텍스처나 별도 게임 파티클 없이 GLB 애니메이션에 포함됩니다.
- v2의 좌우 다리 길이와 발 접지 교정을 보존했습니다. 대기/걷기 반복 경계와 불꽃 반복 경계 검사도 통과했습니다.

검토용: `fox-motions-v3.mp4` (대기·걷기 정면/측면, 시전 정면/측면, 피격, 사망).
모델: `fox-animated.glb`, 편집본: `fox-animated.blend`.
측정 기록: `verification.json`, `before.json`, `after.json`, `effects-verification.json`.

이 파일은 검토 후보입니다. 사용자 승인·게임 실행 연결은 아직 하지 않았습니다. 시전 중 오른발 들림은 이전 시전 모션에 남아 있습니다. 기존 원본/v2와 유료 Tripo 작업은 그대로 보존했습니다.
